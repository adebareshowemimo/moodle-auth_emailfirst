# Post-registration destination

Emailfirst provides a **Post-registration destination** setting under its
authentication plugin settings. The value must be a local Moodle path.

The default destination is:

`/local/moderncommerce/learner/index.php`

This destination is used after immediate registration and by the Continue
button after email verification. If **Redirect to auto-enrol course** is
enabled and a configured course enrolment succeeds, the course URL takes
precedence.
