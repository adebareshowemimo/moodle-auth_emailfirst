# Email First Authentication

Current release: **v1.3.3**

Email First provides Starter U's branded login and registration pages, with optional navigation buttons for signed-out visitors.

The navigation Register button follows the active theme's primary brand colour even when Boost Union applies its light-button styling to other navigation actions. Administrators can still set an explicit button colour in the plugin settings.

The first registration screen collects age, industry, and the entrepreneurship multiplier answer. Selecting Other reveals a free-text industry field. These answers are saved to the existing Moodle profile fields using the same industry codes as the original Starter U registration form.

The account signup form also asks how the learner heard about Starter U. The dropdown uses existing site choices when available and records the answer in the referral survey report.

Install or update the plugin by uploading the `emailfirst-v1.3.3.zip` archive through Moodle's plugin installer, then complete Moodle's upgrade process.
