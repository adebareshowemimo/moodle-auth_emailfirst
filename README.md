# Email First Authentication

Current release: **v1.3.1**

Email First provides Starter U's branded login and registration pages, with optional navigation buttons for signed-out visitors.

The navigation Register button follows the active theme's primary brand colour even when Boost Union applies its light-button styling to other navigation actions. Administrators can still set an explicit button colour in the plugin settings.

Install or update the plugin by uploading the `emailfirst-v1.3.1.zip` archive through Moodle's plugin installer, then complete Moodle's upgrade process.
